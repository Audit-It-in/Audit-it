# Development Guidelines

## Testing Strategy

**Current Status**: Testing is not a priority for the current development phase.

- We are focusing on rapid feature development and implementation
- Testing will be revisited in a later phase of the project
- Do not include test creation or test-related tasks in implementation plans
- Focus on functional implementation and user-facing features

## Implementation Priorities

1. **Core Functionality**: Implement working features that users can interact with
2. **User Experience**: Focus on UI/UX and user workflows
3. **Data Integration**: Ensure proper database operations and API integrations
4. **Performance**: Basic performance considerations for user experience

## Task Planning

When creating implementation tasks:

- Exclude test writing tasks
- Exclude test setup tasks
- Focus on component implementation, service layer development, and UI creation
- Prioritize end-to-end functionality over test coverage

This approach allows for faster iteration and quicker delivery of user-facing features.
